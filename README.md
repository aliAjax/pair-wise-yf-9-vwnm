# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 离线协作：可续作的改动账

几个搭子各自用浏览器维护同一份规则卡库，桌游吧没网时照常改，回网后逐条合并：

- **改动账（事件溯源）**：所有改动都是追加式账本条目，每条带全局修订号；素材库由账本回放得出，可续作、可追溯。
- **断网暂存、回网合并**：点「断网」后改动进本机离线批次，回网后逐条并入共享账本；合并失败的批次保留，只重试没进去的条目。
- **冲突保留双方**：两人基于同一基准修改同一张规则卡时，两份内容都保留、标出差异（红删绿增），后到不盖先到。
- **复习确认随内容失效**：每张规则卡的复习确认绑定修订号，规则内容一变（修订号增长）确认立即失效，需重新确认。
- **基准迁移**：旧数据没有修订号，首次打开自动包成基准修订 1。
- **容量排队**：待办累计到上限时新改动进队列，草稿不丢，回网后继续合并。
- **多标签同步**：同一浏览器开多个标签即模拟多个搭子，通过 `BroadcastChannel` + `storage` 事件实时同步；也可用「一键演示两人改同一张卡」「模拟对方改」单机演示冲突。

顶部可切换在线/离线、查看待合并数、冲突保留数和容量条；下方「改动账与同步」面板可看重试/放弃批次、待并入和最近改动账。
