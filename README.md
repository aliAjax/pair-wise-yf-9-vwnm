# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 可续作的改动账（离线协作）

几个开局搭子各自用浏览器维护同一份卡库，桌游吧里没网也能照常改，回网后逐条对账：

- **改动账**：收藏桌游、规则卡、开局前复习确认全部是带修订号的变更条目。断网时改动进入本地"待合并差异"批次，回网后逐条合并进共享账本（另一个 localStorage 键，模拟大家汇合的那本账）。
- **同卡冲突**：两个人同时修改同一张规则卡时，后到的不盖掉先到的；两份内容都留在冲突面板里，并用字符级差异标出改动（红删绿增）。可以把"我的改动"另存为新卡，或放弃。
- **复习确认失效**：确认绑定规则卡的修订号。规则内容一有变化修订号就 +1，相关复习确认立即失效，详情页"开局前复习确认"区会要求重新确认。
- **基准修订迁移**：旧数据没有修订号，首次打开时自动迁移成基准修订（rev 1），并在回网后落账。
- **失败续作**：合并中途失败时，已落账的条目不会重试，离线批次里没合并进去的那些保留下来，下次只重试它们。
- **容量排队**：待确认差异到上限（30 条）后，新改动先排进草稿队列，草稿不丢、本地可见，同步腾出空间后自动补进待合并。

顶部同步条显示在线状态、待合并差异、排队草稿、未解冲突和上次同步时间；"模拟断网"开关可以在有网环境下演练离线流程。多个标签页之间改动会通过 `storage` 事件互相同步。

## 测试

```bash
npm test
```

- `test/sync.test.mjs`：改动账引擎端到端验证（迁移、逐条合并、冲突双留、确认失效、失败重试、容量排队）。
- `test/smoke.dom.mjs`：最小 DOM 桩跑通启动路径（旧数据迁移 -> 基准修订落账 -> 页面渲染）。
